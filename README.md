# Student Data Analysis

## Overview
This project analyzes student marks using Python.

## Files
- Task1.py - Python script for data analysis and visualization
- student_data.csv - Dataset containing student marks

## Features
- Load CSV file using Pandas
- Display student data
- Calculate average Math marks
- Bar chart of Math marks
- Scatter plot of Math vs Science
- Correlation heatmap

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## How to Run

1. Install the required libraries:
```
pip install pandas matplotlib seaborn
```

2. Run the program:
```
python Task1.py
```

## Output
The program displays:
- Student data
- Average Math marks
- Bar chart
- Scatter plot
- Correlation heatmap
